# Lzhecord 0.6.3 — браузерный вариант для Windows

Голосовые комнаты и трансляции для небольшой компании через Radmin VPN. Совместный просмотр и голосовое общение доступны бесплатно, без подписки Discord Nitro.

Это альтернативный браузерный вариант, а не более новая desktop-версия. Для обычного первого запуска рекомендуем [приложение 0.7.0](https://github.com/evanc0/Lzhecord/releases/tag/v0.7.0).

## Запуск

1. Скачайте **`Lzhecord-Radmin-0.6.3.zip`** из Assets. Автоматический **Source code** не содержит готовую программу.
2. Распакуйте архив целиком в доступную для записи папку пользователя.
3. Убедитесь, что установлен Edge или Chrome, и запустите **`START.cmd`**.
4. Подключитесь с друзьями к одной сети Radmin VPN и войдите в комнату.

Windows 10/11 x64. Node.js и нативный захват включены. Самостоятельное открытие HTML не заменяет запуск через START.cmd. Не запускайте одновременно с desktop-версией: они используют одни порты.

Есть голос, выбор микрофона и порога активации, захват экрана/окна, отдельные настройки качества и темы с анимацией. Системный звук в основном захвате относится ко всему компьютеру; исключение звука комнаты включается отдельно.
