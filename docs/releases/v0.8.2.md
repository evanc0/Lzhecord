# Lzhecord 0.8.2 — голос собеседника до 200%
+
+Теперь тихий микрофон друга можно усилить у себя: **⋯ рядом с участником → Громкость участника → 0–200%**.
+
+- Громкость выше 100% реализована через Web Audio GainNode: 200% даёт двукратную амплитуду принятого голоса. Это реальное усиление, а не только новое значение ползунка.
+- Изменение действует только у слушателя и касается голоса выбранного собеседника.
+- Личный мут и кнопка наушников заглушают также усиленный голос. После включения возвращается выбранный уровень, например 200%.
+- Выбранный уровень сохраняется при восстановлении связи внутри текущей комнаты. При выходе из комнаты настройки участников сбрасываются.
+- Исправления системного звука из 0.8.1 сохранены. Протокол совместим с 0.8.0 и 0.8.1; для новой регулировки обновиться нужно слушателю.
+
+## Как обновить
+
+Закройте старую версию, распакуйте **Lzhecord-Desktop-0.8.2-win-x64.zip** целиком в отдельную папку и запустите **Lzhecord.exe**. Настройки можно перенести файлом data/preferences.json, GPU-компоненты — каталогом data/media-tools при закрытом приложении.
+
+## Проверка
+
+В собранном Windows EXE проверена амплитуда реально принятого по WebRTC голоса до и после усиления: при 200% она удваивается. Проверены личный мут с восстановлением 200%, выключение звука комнаты, обычная трансляция и сохранение исключения голоса Lzhecord из системного звука. Отдельная повторная проверка GPU-видео в этой версии ограничена активной пользовательской трансляцией на машине разработки; GPU-кодировщик и передача видео не менялись.
