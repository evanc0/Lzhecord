# Lzhecord 0.7.0 — приложение для Windows

**Смотрите фильмы, показывайте экран и разговаривайте с друзьями бесплатно — без Discord Nitro.** Lzhecord может быть альтернативой, когда Discord недоступен; для этой версии нужен работающий Radmin VPN у всех участников.

Пробная desktop-сборка для Windows 10/11 x64. Внутри собственный Chromium, голосовые комнаты, нативный захват монитора или приложения и системного звука. Платного ограничения настроек качества нет; фактическая плавность зависит от компьютеров и соединения.

## Скачать и начать

1. Скачайте **`Lzhecord-Desktop-0.7.0-win-x64.zip`** из Assets ниже. **Source code** — это архив материалов страницы, а не приложение.
2. Распакуйте **весь архив** и запустите **`Lzhecord.exe`**. Не переносите exe отдельно от соседних файлов.
3. Подключитесь с друзьями к одной сети Radmin VPN, создайте комнату и включите микрофон или показ экрана.

Node.js, .NET и внешний браузер устанавливать не нужно. До пяти человек в комнате: создатель и четыре гостя. Одновременно доступна одна трансляция. Комнаты предназначены для доверенной компании внутри VPN; дополнительного пароля Lzhecord нет.

## В этой версии

- Отдельное окно приложения с собственным движком.
- Голос, мут, выключение звука комнаты, выбор микрофона и порог активации.
- Основной захват без рамки с исключением звука Lzhecord из системного микса.
- Выбор монитора или окна по карточке; резервный захват Chromium.
- Отдельные разрешение, FPS и битрейт с изменением во время трансляции.
- Профили, аватарки и 18 тем, включая анимированные.
- Исправлен запуск из Program Files: при запрете записи настройки сохраняются в `%APPDATA%\Lzhecord\data` без прав администратора.

## Перед первым тестом

Выйдите из комнаты старой версии и закройте её. Для первого подключения используйте одинаковую сборку у всех. При необходимости разрешите доступ Lzhecord к используемой сети в брандмауэре Windows.

Основной захват окна передаёт системный звук, а не только звук выбранного окна. Для исключения голосов оставьте соответствующий переключатель включённым. В резервном способе возможны рамка и возврат голосов в стрим.

Проверены локальное подключение двух окон, голос с тестовым устройством, оба способа захвата, исключение собственного звука и смена FPS. Это не гарантия производительности на другом ПК или через любой VPN. Сборка не подписана сертификатом издателя.

Рядом с архивом опубликован `SHA256SUMS.txt` для проверки целостности загрузки. Бесплатное использование приложения разрешено; свободная лицензия на собственный код не предоставлена.
